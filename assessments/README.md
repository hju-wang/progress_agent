# assessments —— 检测试卷资产

这里存放**具体题目组成的试卷**，而不是“会不会/了解不了解”的自评。

## 原则

- 每个题目都指向具体能力项（如 `A4`、`B2`），有可判定的答案或验收标准。
- 客观题（选择/填空）机器可判；实操与代码题由教练按验收标准批改。
- 试卷成绩取代自评，作为更新能力档位与差距报告的依据。

## 评分规则（2026-09-10 起）

- **每张试卷满分 100 分**，题面必须标注每题分值；主观题可拆子点，分值合计必须为 100。
- 客观题（单选/填空）：答对得满分，答错 0 分，不设部分分。
- 主观题、读代码题、设计题：按验收要点给分，缺一个要点扣对应子分。
- **通过线 ≥ 80 分**；低于 80 分需补齐后重批（可只重做失分题）。
- 每次批改必须输出：逐题得分 + 总分 + 是否通过 + 失分点与改进建议。
- 由教练给参考、用户誊写的内容不能计为“独立作答”，必须在批注中标注，并在 Day 6 独立检验中复查。

> 历史版本：Day 2 / Day 3 的 v0.1 试卷未标分值；如需复测或重考，按新规则出新版。
