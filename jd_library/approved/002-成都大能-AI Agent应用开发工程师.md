## 岗位职责（摘要）

1. 面向嵌入式软件研发场景的 AI Agent：客户需求理解、任务拆解、代码生成/修改、编译验证、错误分析及自动修复。
2. Agent Tools、MCP Server 设计开发与集成：文件操作、代码分析、编译构建、测试、日志分析、内部业务系统接入。
3. 基于 LangGraph / LangChain / LangFlow 开发和优化 Agent 工作流：任务规划、Tool Calling、上下文管理、执行成功率。
4. RAG、代码知识库与模型调用能力建设：让 Agent 理解 SDK、API、技术文档、规范与历史代码。
5. 与 VS Code Extension / Web IDE 集成：代码上下文获取、修改、Diff 展示、编译验证与结果反馈。

## 任职要求（摘要）

- 熟练使用 Python，具备良好软件工程与后端开发能力。
- 有 LLM 应用开发经验，熟悉 Agent、Tool Calling、RAG。
- 熟悉 LangGraph / LangChain / LangFlow 等一种或多种并有实际项目经验。
- 加分：MCP、Coding Agent、AI 编程助手经验；VS Code Extension/Web IDE 集成；TypeScript；Git/Linux/Docker；C/C++ 编译构建流程。
