# Day 8：独立检验（限时 90 分钟 · 少 AI）

这个项目是一个迷你 Agent 工具循环（注册表 + `run_agent` + 离线假模型）。
里面**埋了 3 个缺陷**：2 个会让现有测试失败，1 个现有测试覆盖不到、需要你自己写测试才会暴露。

## 规则

- **限时 90 分钟**：自己计时，到点停手，按现状提交（没做完也算结果）。
- **少 AI**：可以看自己的代码、本 README、Python 标准库文档；**不许问 AI 要修复方案或测试代码**。
- 可以运行命令、看报错、调试；卡住超过 15 分钟就先记录卡点继续往下走。
- 不要改现有测试的断言意图（它们描述的是正确行为）。

## 验收标准（正确行为）

1. 同一工具**连续失败满 2 次**后，后续请求不再真正执行，直接回填
   以 `[工具错误]` 开头、说明“放弃重试”、带工具名的结果；且仍是 `role="tool"` + 原 `tool_call_id`。
2. 该工具**成功执行一次**要把它的连续失败计数清零（失败→成功→失败→失败，第 4 次仍应真正执行）。
3. 两个 `ToolRegistry` 实例**互不影响**：往一个注册表注册工具，不会污染另一个。
4. 其他路径不变：日期问题能正常回答；未知工具抛 `ValueError`。

## 交付三样

1. 修好 `app.py` 里的 3 个缺陷；
2. 在 `tests/test_app.py` 里**新增至少 2 个测试**：一个能暴露“隐藏缺陷”，一个覆盖边界
   （例如成功清零、`tool_call_id` 协议、未知工具）；
3. 在 `NOTES.md` 里写根因分析：每个缺陷的「现象 / 根因 / 修复 / 如何防复发」。
