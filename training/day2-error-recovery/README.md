### 学会/巩固的点

- **工具错误是模型的输入，不是进程的终止条件**：异常转成普通字符串结果回填，模型才能基于错误诚实收尾。
- **消息协议不变量**：assistant 发出 `tool_calls` 后，每个 `tool_call_id` 都必须有一条 `role="tool"` 结果——错误路径和“放弃重试”路径也不能漏。
- **验收要用确定性标准**：真实模型很会“圆场”，可能掩盖机制缺失；mock 以 `[工具错误]` 前缀判断，确保异常转换真的发生，而不是模型碰巧读懂。
- **限流设计要点**（见试卷 Q5 参考答案）：计数器跨轮累计、超限不再执行、只有真失败才 +1、放弃时仍回填 tool 结果。
