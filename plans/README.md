## 训练节奏：day 不会无限循环

- “Day”是按**完成度**推进的训练模块，不是日历日；Day 2 没验收，就不开 Day 3。
- 每个模块完成 → 总结进该模块 README → 更新 `training/README.md` 与 `training/NEXT.md` → `git commit`。
- 每周或每完成一轮模块：重跑自测 + 差距报告，由数据决定：继续下一轮 / 调整方向 / 提前切换阶段。
- 明确的停止条件：绿灯 + offer（结束求职冲刺）；连续两周无实质提升（触发重新规划，而不是盲目 day）。
